# Pangolin Rush Collection

A retro speed-platformer collection made for GitHub Game Off 2026 (theme: SHIFT).

Explore Rush Island, a 3D hub with a portal to each of four games: two 2D and two 3D. Touch a SHIFT orb to flip gravity and run along the ceiling. Pick from 7 runners, each with their own move, and hunt down 12 Gold Medals, a Ring Race, a hidden vault and a secret boss.

## Play
Open `index.html` in any modern browser. No install needed.

Controls: Arrow keys to move or steer, Space to jump, X for your runner's ability, Shift for air moves.

## Runners
- Pip the pangolin: fastest runner, Scale Dash
- Juno the sugar glider: Glide and Dive
- Spikes the tenrec: Ground Pound and Quill Burst
- Suzie: Heart Hop double jump
- Proto Pip: Overdrive boost
- Kai the chameleon: Tongue Zip
- Nova: Star Hover and Stardrive

## Source
`index.html` is the whole game in one file. It is built by `build.py` from the four games (`g1.html` to `g4.html`) and the hub (`hub.js`).
